# Vendor a pinned Trigger.dev UI slice

Skyline will vendor the reachable client-side UI closure rooted at Trigger.dev's shell, Runs page, trace viewer, and inspector from commit `ca9a74e84abdf9483c234e82dc54b9ec2c00d8c0`, while keeping Skyline routing, DTO adapters, API access, and branding outside the derived source. The contributor build pins Trigger's React 18, Vite, Tailwind 4, Node, pnpm, and splitter-patch constraints, then ships fingerprinted assets from the Composer package without a Remix server or consumer Node setup. Upstream refreshes are deliberate manifest-driven imports verified by licensing, type, build, interaction, and visual checks because a package dependency, submodule, full webapp fork, or visual reimplementation would either retain Trigger's server coupling or lose interface fidelity.
