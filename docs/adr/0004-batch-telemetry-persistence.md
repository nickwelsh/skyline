# Batch telemetry persistence within a bounded delay

Skyline supersedes ADR 0003's immediate-lifecycle transaction clause with no-sampling, bounded-delay batches. Capture hooks buffer every lifecycle record and span, reduce them into the normalized Trace, Run, Attempt, and span tables, and flush transactionally after 5,000 operations, after two seconds at a Laravel worker-loop boundary, at every terminal queue Attempt boundary, on normal application termination, or explicitly before a read-after-write proof. This preserves bounded writes without leaving completed retries stranded in a long-lived worker; live queued/running state remains best-effort and a hard process kill can lose the unflushed window. Terminal data remains idempotent, pruning remains whole-Trace, and persistence failures remain isolated and rate-limited.
